# Package Manifest

This package is durable project memory. It intentionally excludes application source copies, build artifacts, credentials, production exports, and old chat transcripts.

`00_START_HERE.md`
= instructions for bootstrapping a completely fresh Codex session

`README.md`
= North Star / objective / roadmap

`AGENTS.md`
= permanent Codex operating rules

`docs/HANDOFF.md`
= compact continuity from the retired chat

`docs/PROJECT_STATE.md`
= exact documented current project state

`docs/ARCHITECTURE.md`
= how the system currently works

`docs/DECISIONS.md`
= important durable decisions

`docs/KNOWN_ISSUES.md`
= broken, risky, uncertain, or messy areas

`docs/NEXT_TASKS.md`
= prioritized work from here

`docs/DATA_AND_SERVICES.md`
= live data, external services, integrations, and preservation requirements

`docs/NEW_CHAT_STARTER.md`
= tiny fallback message if the new Codex interface requires an opening prompt
