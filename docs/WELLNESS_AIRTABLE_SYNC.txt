Each source selection keeps its exact ID, including newer session IDs missing
from the older checkout. Legacy rows say Signup received, never a newly confirmed
place. Ledger rows reflect registered/waitlisted/cancelled and FIFO position;
pending source materialization and unmigrated rows need review. Explicit test rows
are excluded. Duplicate identities, broken booking references and missing fully
materialized sources fail the snapshot. SourceRevision excludes sync time so retry
previews keep the same content hash. Cancelled rows remain; no delete instructions.

Guest/session links require verified record-ID mappings. No name-only/fuzzy guest
matching or creation of Guest Tracker rows. Missing mappings omit link fields and
mark review issues, preserving any existing links; Staff Notes is always omitted.
The shipped handlers supply no mappings yet. This is not an active live sync.
